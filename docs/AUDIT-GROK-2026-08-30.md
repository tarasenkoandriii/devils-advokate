# Grok/xAI — сверка с silverfinance, 2026-08-30

По прямому запросу («использовать GrokAI from silverfinance»). silverfinance
использует Grok для мультимодальной оценки товара (`ai-estimate.ts` — фото →
категория/название/описание/цена, плюс сортировка фото для 360°-показа). У
devils-advocate-project нет мультимодального сценария для Grok — `ai-provider-client.ts`
(проверен ранее сегодня, без находок) отправляет только текстовые промпты через все
три провайдера одинаково, добавлять vision-контент под несуществующий сценарий не
стал бы (спекуляция, не расширение). Ценность нашлась не в архитектуре, а в одной
конкретной, добытой боем детали: имени модели.

## Находка — `grok-4` официально снят с производства 15 мая 2026

Комментарий в коде silverfinance: «The old grok-2-vision-1212 name returns HTTP 400
(model not available)» — прямое свидетельство того, что имя модели xAI устаревает и
ломается без предупреждения в самом ответе API (не мягкая деградация). Проверка по
официальным источникам (docs.x.ai, зеркала документации через Oracle OCI, promptfoo
provider docs) подтвердила: `grok-4` и вся линейка `grok-4-*`/`grok-3` **retired
2026-05-15**. Запросы к retired-слагам сейчас технически проходят — xAI молча
редиректит их на `grok-4.3` — но:

- тарификация идёт по цене `grok-4.3`, не по ожидавшейся цене `grok-4`;
- `reasoning effort` через редирект становится `low`/`none` неявно, не тем, что
  выбрал бы сам вызывающий код, если бы указывал модель напрямую;
- сама xAI прямо рекомендует «для новых конфигураций используйте актуальный
  canonical model ID напрямую», не полагаться на редирект как постоянное решение.

`devils-advocate-project`'s `prisma/seed.ts` был настроен именно на `grok-4` —
retired-слаг. Не поломка сегодня (редирект работает), но код тихо не соответствовал
бы тому, что думает, что вызывает.

## Исправлено

`AIModel.name` и `AIModelVersion.version` для xAI: `grok-4` → `grok-4.3` —
подтверждённый рабочий слаг, тот же, на который мигрировала silverfinance после
поломки более старой модели. Не самый новый флагман xAI на сегодня (Grok 4.6 вышел
12 августа 2026, Grok 4.5 — 8 июля) — осознанно взят слаг, для которого есть прямое
production-подтверждение работоспособности, а не самый свежий неподтверждённый.
Комментарий в `schema.prisma` обновлён (список моделей в поле `name`). SQL для уже
засеянной production-БД — в конце `schema_audit_2026_08_30.sql`: `UPDATE`, не
`upsert` через seed.ts заново — иначе создалась бы новая строка `AIModelVersion` с
новым `id`, разойдясь с историческими ссылками на старую версию в записях
инференсов.

## Итог

`tsc` чист, schema.prisma валиден, jest 63/516, standalone 677 — без изменений в
счёте (правка не в коде с логикой, только в данных сида и комментарии схемы, тестов
на конкретное имя модели не было и не должно быть — оно тестируется не как
поведение, а как конфигурация).
