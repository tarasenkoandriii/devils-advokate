# Аудит проекта — 2026-08-30

Внешний аудит монорепо (api / tma / admin / landing) с чистой установки по
`package-lock.json` (`@types/node 20.19.43`, TypeScript 5.9.3, Prisma 5.22,
Next 14.2.35). Всё ниже — проверено выполнением, не чтением.

## 1. Сборка и типы (исправлено)

Причины (все — «код никогда не проходил настоящую проверку типов, только
`ts-node --transpile-only`»):

1. `response.json()` в `@types/node ≥ 20.19` типизирован как `unknown` —
   ~50 обращений к полям в клиентах внешних API (`ai-provider-client`,
   `google-places-client`, `open-meteo-client`, `nominatim-client`,
   `serpapi-client`, `vercel-blob`, `vision-ocr-client`,
   `telegram-bot-client`, `live-session.service`). Исправлено явной
   аннотацией (runtime-проверка формы там и так есть).
2. `const created = []` → `never[]` под `strictNullChecks` в 11 сервисах
   (`manipulation-detector`, `discrepancy-analysis`, `turning-points`,
   `do-not-say`, `scheduler-advice`, `live-manipulation`,
   `live-argument-tracking`, `communication-profile`, `source-conflict`,
   `venue-recommendation`, `probing-detector`). Исправлено явными
   Prisma-типами; `let signal = null` → `ConversationSignal | null`.
3. `@ts-expect-error` на `duplex: 'half'` в `transcription.service.ts`
   стал «unused» — заменён на `as RequestInit`.
4. `apps/tma`: `import('sherpa-onnx-wasm')` — пакета нет в зависимостях
   (динамический import с честным null при отсутствии), но TS2307 ломал
   `next build`. Добавлена декларация `src/types/sherpa-onnx-wasm.d.ts`.
   Плюс 10 ошибок `Uint8Array<ArrayBufferLike> → BlobPart` в двух спеках —
   тот же класс, что уже исправлялся в Пункте 89 (широкая аннотация
   возвращаемого типа), исправлено `Uint8Array<ArrayBuffer>`.

## 2. Логический баг (исправлено, покрыто тестом)

`MediaReviewService.getQueue()` синхронизировал статус элемента с
`Conversation.status` **только когда элемент в `READY`**. Элемент проходил
READY→PROCESSING на первом GET и **навсегда оставался в PROCESSING** — до
`DONE` не доходил никогда. Именно на это указывала ошибка TS2367
(`'READY'` vs `'PROCESSING'|'DONE'`). Условие расширено на `PROCESSING`,
добавлен регрессионный тест на второй GET.

   нет — код и модели живут мёртвым грузом в схеме (4.6k строк
   `schema.prisma`).

   решение не принято) — не трогал.
