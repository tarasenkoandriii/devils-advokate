# Песочница: сводный отчёт покрытия (2026-09-01)

Итог шести этапов плана доменного покрытия (Пункты [sandbox-cycle-2],
[sandbox-health], [sandbox-major-purchase], [sandbox-investment],
[sandbox-interview-pool], [sandbox-family-law], [sandbox-dtp]).
Песочница — операторский стенд на вкладке Sandbox админки: всё
выполняется продовыми сервисами от имени самого оператора, без
имперсонации и без обходов проверок; отказ проверки — результат
прогона, не сбой.

## Что покрыто

**Сквозная инфраструктура.** Чеклист готовности (БД, seed, ключи,
CORS, согласия — 13 пунктов с интегральным статусом), выдача согласий
оператору (5 типов, source=admin-sandbox), транскрибация (синтетический
WAV и реальный файл до 500 МБ), YouTube-поиск, очередь медиа-разбора с
прогресс-индикатором, кнопками «Повторить» и «Диагностика» (живой
статус у провайдера, самолечение lease, внеочередной опрос), аккордеон
разбора (сегменты + сигналы + метаданные), Fact Check двухслойной
кнопкой (база фактчеков + AI-гипотезы с кэшем 24 ч), intake-квиз с
голосовым вводом (как в TMA: токен → браузер → AssemblyAI напрямую) и
dispatch во все 6 доменов.

**Домены — каждый после dispatch из intake-квиза, до конфига и своей
«жемчужины»:**

| Домен | Цикл в песочнице | «Жемчужина» | AI-вызовы |
| --- | --- | --- | --- |
| Здоровье | ответы → extract → конфиг → лабдокумент | Vision OCR с verify (изображение не персистуется) | extract; OCR |
| Крупная покупка | ответы → чек-лист → extract → конфиг → варианты | сравнительная таблица вариантов | чек-лист; extract |
| Инвестиции | ответы → extract → конфиг → возможность → источник | сырой текст источника БЕЗ AI-оценки «выгодности»; таблица без score/rank; смоук групп | extract |
| Подбор персонала | ответы → extract → конфиг → анкета → кандидат → релевантность → отчёт | compliance-флаги с цитатой; «AI предлагает, человек утверждает» двумя кнопками; смоук команды | extract; анкета; релевантность |
| Семейное право | ответы → extract → конфиг → стороны → активы → бюджет | черновик протокола урегулирования с дисклеймером «не юридический документ» (без AI) | extract |
| ДТП | ответы → extract → конфиг → участники → вина → доказательство | chain of custody: sha256 сервером, append-only журнал доступа, ноль AI по доказательствам | extract |

## Где тратятся реальные деньги и квоты

AssemblyAI (транскрибация файлов и живой голосовой ввод — поминутно),
Gemini Interactions (мультимодальный разбор YouTube — самая дорогая
операция, потолок длительности управляется env
MEDIA_REVIEW_MAX_DURATION_SECONDS), LLM-вызовы extract/анкета/
релевантность/чек-лист/AI-фоллбек факт-чека (через AIRouter, по
активной capability), Cloud Vision OCR (лимит 10/сутки на
пользователя, общий у оператора с его TMA-аккаунтом — осознанно),
YouTube Data API и Fact Check Tools (квоты; ответы кэшируются 24 ч).
Лимиты нигде не обходятся.

   отдать реальному второму TMA-аккаунту.
3. **Интерактивные live-фичи TMA** (подсказки в разговоре и т.п.) —
   живой сессии в админке нет; голосовой ввод покрывает транспорт.

## Как прогонять регрессию после деплоя

Шаг 1: чеклист зелёный → Шаг 3: квиз (пресетом) → dispatch в домен →
пройти панель до «жемчужины». Для медиа-конвейера: Шаг 2 → очередь →
DONE → Fact Check. Любая красная строка — это либо конфигурация
(чеклист скажет какая), либо честный продовый отказ (текст говорит
какой), либо баг — тогда с текстом ошибки в этот чат.
