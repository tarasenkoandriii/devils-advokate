# ТЗ: hero-иллюстрации и набор иконок лендинга (hero + icons)

Дата: 2026-09-01. Статус: ТЗ (графика не отрисована).
Основание: аудит лендинга [landing-audit] 2026-09-01 — в словарях
лендинга объявлено 29 полей `icon:` и НИ ОДНО не рендерится (нет ни
компонента иконки, ни самих ассетов); страница /jobs выпущена v1 без
единой иллюстрации. Это ТЗ закрывает оба пробела одним согласованным
стилем.

## 0. Контекст

Лендинг — тёмная сдержанная база (`--bg #11141a`), дисплейный шрифт
Unbounded, сигнатурный мотив — триада «накала разговора»
green/amber/red (`--signal-calm #3fbf7f`, `--signal-caution #e8b84b`,
`--signal-critical #e2634f`), используемая как тонкие линии-акценты,
не заливки. Существующие hero-иллюстрации (courtroom, hell, lawyer,
slogan) — растровая живопись, после аудита пережаты в WebP; их
перерисовка НЕ входит в это ТЗ (брифы devils-advocate-hero-brief.md и
смежные остаются источником по ним).

## 1. Объём

### 1.1 Hero для страницы /jobs (1 иллюстрация)

Сейчас hero /jobs — чистая типографика. Нужна одна иллюстрация в той
же живописной технике, что courtroom-серия, но с СЮЖЕТОМ БЕЗ СУДА:
стол, за которым человек раскладывает своё — записи, страницы,
конспект разговора; напротив — пустой стул с папкой «CV» ИЛИ два
человека в спокойном разговоре (интервью), без экзаменационной
интонации. Настроение — «подготовленность», не «испытание».

Запрещено в кадре: детектор лжи и любые «сканирующие» линии над
головой человека; красные метки «ложь/правда»; рейтинги и звёзды над
людьми; логотипы реальных джоб-сайтов и компаний; читаемый текст,
похожий на реальное резюме реального человека.

Формат: исходник ≥1536×1024, поставка WebP q85 ≤ 300 KB; светлая
версия не нужна (лендинг одностилевой тёмный).

### 1.2 Набор иконок (34 шт.)

Единый стиль: stroke 1.5px на сетке 24×24, скруглённые окончания,
без заливок; цвет — `currentColor` (страница задаёт `--text-muted`,
акцент — один элемент иконки допускается в цвете триады, не более).
Поставка: инline-SVG как React-компоненты (`src/components/icons/`,
именованные экспорты по slug), `aria-hidden="true"`, без width/height
в разметке (размер через CSS), `viewBox="0 0 24 24"`, path-only (без
растровых вложений), каждый файл ≤ 2 KB.

Слаги и назначение (из словарей, где они уже объявлены):

- **Hero-callouts (6)**: `shield-check`, `case-dossier`, `context`,
  `waveform-alert`, `scales`, `lock`.
- **Technology/phone-строки и группы (по словарю, 23)**: `calendar`
  (×2), `chatgpt`, `voice_recorder`, `notes`, `email`, `files`,
  `chat`, `wifi`, `servers`, `integrations`, `document` (×2),
  `shield` (×2), `lock` (второе вхождение — тот же ассет), `target`,
  `rocket`, `person`, `people`, `lightbulb`, `brain`, `alert`.
  Повторные слаги — ОДИН ассет, переиспользование.
- **Страница /jobs (5 новых)**: `cv-draft` (лист с пером),
  `link-vacancy` (звено цепи + документ), `stats-simple` (три
  столбика), `questionnaire` (список с галочкой), `coverage`
  (кольцо-прогресс с засечками). Слаги добавить в jobs-словарь при
  внедрении.

Смысловые запреты на образы: никаких «полиграфов», «лай-детекторов»,
масок лжеца, носа Пиноккио (противоречит §7.4 продукта); никаких
звёзд-рейтингов людей; `waveform-alert` — волна с меткой ВНИМАНИЯ
(нейтральный маркер сигнала), не «детект лжи».

### 1.3 Внедрение (код, после отрисовки)

Компонент `Icon` (map slug → компонент) + рендер в Hero-callouts,
Technology-группах и карточках /jobs. Поля `icon:` в словарях уже
есть — внедрение НЕ меняет тип Dictionary. Фолбэк: неизвестный слаг
рендерит ничего (не ломает страницу), в dev — console.warn.

## 2. Acceptance

1. 34 SVG проходят SVGO без изменений >5% (уже оптимизированы), все
   ≤ 2 KB, один viewBox, ни одного `fill` кроме `none`/`currentColor`.
2. Иконки различимы при 16px и при 24px на фоне `--bg-card`.
3. Hero /jobs ≤ 300 KB WebP, LCP страницы на мобильном не ухудшается
   более чем на 0.3 c против текстовой версии.
4. Ни один ассет не содержит запрещённых образов из §1.1/§1.2.
5. Словарные `icon:`-поля рендерятся на всех трёх языках одинаково
   (иконки языконезависимы).

## 3. Вне объёма

Перерисовка courtroom-серии; анимированные иконки; светлая тема;
фавиконы и app-иконки TMA (другой пайплайн).
